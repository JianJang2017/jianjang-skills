# 八段式提示词框架 · 填空模板 · 完整实例 · 负面词库

## 八段式描述顺序

信息顺序清晰比形容词堆砌重要得多。固定按此顺序写：

1. **版式与布局声明**（从 layout-templates.md 选）
2. **人物基础设定**：年龄、身份、身形、气质（气质写组合层次：「冷艳凌厉、沉稳威严，带有久经沙场的克制感与贵族武将的压迫感」，不写单词）
3. **五官与神情**：脸型、肤色、眉眼、鼻唇、神情——具体描述服务于身份，减少模型自由发挥导致的风格漂移
4. **发型发饰**：发髻结构、碎发、发饰材质与造型
5. **妆容**：按 9 部位择要写（设定图至少写眼妆和唇色）
6. **服装与材质**：结构 + 主色 2-3 个 + 材质 + 纹样 + 配饰
7. **姿态构图**：站姿 + 一致性话术（全身、无裁切）
8. **背景灯光 + 画质尾缀 + 负面提示词**

## 分维度标签式模板（写实定妆照向，与八段式二选一）

八段式是"叙述流"，标签式是"档案流"——每个维度前置标签名，信息密度更高，写实定妆照/男主设定实测效果好。骨架：

> 生成一张【风格主题】的【性别】角色四视角定妆照，通过正面近景、正面全身、侧面、背面四个维度，完整展示一套【造型概括】。
> **样貌特征**：【骨相】，【脸部线条】，【眉眼】，【瞳色】，【鼻】，【唇】，自带【气质关键词】，适配【人设列表】。
> **神态表情**：【眼神】，【面部情绪】，传递出【气场描述】，适配【剧种/戏份】。
> **发型**：【发型结构】，【发丝质感】，【鬓角/刘海处理】，整体【风格收束】。
> **妆容核心**：以【妆造关键词】为核心，【底妆】，【眼妆】，【修容】；【肤质呈现】，塑造【视觉氛围】。
> **配饰细节**：【配饰逐件】，【金属光泽度】，细节【气质导向】。
> **核心色系**：以【主色+辅色】为主色调，【配色逻辑】，整体造型【色彩气质】。
> **服装形制**：【外层】，【内搭】，【下装】，【鞋】；【版型剪裁要点】，适配【人设】。
> **面料材质**：主体面料为【面料1+面料2+面料3】，【各面料质感对比】，光线照射下层次柔和高级，无浮夸光泽。
> **构图**：四宫格拼接构图，分别展示正面近景、正面全身、侧面、背面（可给每个视角标注侧重点），全方位呈现角色完整造型，适配影视定妆、建模、场景拍摄参考。
> **布光**：专业影棚柔光拍摄，【背景色】极简背景，【光型描述】，保留面部骨相层次，凸显【氛围词】。

技法要点：面料材质写 3 种并强调"质感差异化明显"（如哑光羊毛+高支纯棉+哑光真皮）；配饰用"低饱和轻奢金属，弱化凌厉感"这类功能性描述；每个标签末尾都挂回人设。

## 男性角色描述要点（与女性模板的差异）

结构完全复用八段式，替换描述重心：

- **骨相**：眉骨立体、鼻梁高挺、下颌线利落分明、喉结（写实向可写）；忌套用"精致鹅蛋脸"
- **身形**：肩宽腰窄、挺拔颀长、健硕匀称、清瘦如竹——匹配身份（武将健硕/书生清瘦/帝王挺拔）
- **气质**：清峻疏朗、克制内敛、桀骜锋利、温润如玉、沉静压迫感——同样组合出层次
- **胡须**：干净无须（少年感/仙侠）/ 短髭 / 修剪整齐的络腮——是重要识别点
- **妆造**：不写"妆容"，写"面容干净利落，眉形浓密整齐，唇色自然偏淡"；详见 makeup-library.md 男性章节
- **服装**：古风男装写袍/衫/甲的层次结构（内衬中衣+外袍/罩甲+腰带革带+靴），现代写西装/机能/休闲的版型剪裁
- **负面词补充**：女性化面容（如需硬朗男性时），阴柔气质，浓妆

## 负面提示词库（按类组装，古风/复杂服饰必须全量）

- **低质量**：低清晰度，低质量，过度磨皮，塑料皮肤
- **五官**：五官畸形，面部不对称，眼睛错误，眼睛不对称
- **手部**：手部畸形，多余手指，缺失手指，肢体扭曲
- **比例**：身体比例失衡，头身比例错误
- **服装材质**：服装简陋，布料塑料感，刺绣模糊，发饰杂乱，金属无质感，发丝成块
- **背景**：背景复杂
- **构图裁切**：裁切身体，半身图，缺少鞋履
- **色彩光影**：过曝，强对比，过饱和
- **风格偏移**：浓妆，欧美脸，幼态化，过度性感化，AI伪影
- **通用短版**（国风插画用）：低画质，模糊，手部畸形，变形，五官扭曲，裁剪，水印，文字，logo，重复身体，多余手指，解剖错误，比例失调，光线杂乱

**平台不支持负面词栏时**（GPT-image/Nano Banana）：把关键约束以"无"字短语并入正文结尾——"无文字，无书法，无标识，无水印，无多余元素，无畸变崩坏，无杂乱发丝"。
