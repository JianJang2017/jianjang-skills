# 三视图版式模板与一致性话术

五种经过实测验证的版式，按用途选择。所有模板中的一致性话术为稳定出图的关键，不可删减。

## 版式 A：横版 16:9 角色设定图（默认首选）

**适用**：标准角色设定图、短剧/漫剧人设定稿。

**布局声明写法**：

> 人物设计展示图，16:9横向构图，2048×1152，【风格主题】角色设定图。画面左侧约占40%，放置同一人物的正面头肩大特写，脸部尺寸醒目，头部略微侧倾但双眼正视镜头，深黑瞳孔带清晰眼神光；右侧约占60%，整齐并排展示同一人物的正面、标准右侧面、完整背面三个全身视图，人物、发型、服装纹样、饰品和比例完全统一，脚部完整可见。

**布局声明写法（变体 · 3D古风仙侠男主实测版）**：

> 画面左侧是超大人物脸部胸像正面特写，画面右侧水平并排 3 张全身立绘，依次为正面全身、45°侧面全身，背面全身。

（两种写法功能相同，前者更规范，后者更精简，按风格择一）

**收尾建议**：淡青灰/浅米白摄影棚背景 + "银白细边框和克制的竖向分隔线" + "无文字，无标识，无水印"。

## 版式 B：竖版 3:4 三视图图鉴（发型/妆容特写向）

**适用**：发型图鉴、妆容特写为主的设定图，图内可带标题文字。

**布局声明写法**：

> 高质量【古风人物发型】图鉴，3:4竖版构图，纯净【背景色】背景。画面包含同一位【人物】的三种半身视图：左下为最大正面特写，右上为完整侧面视图，右下为背面视图，三个视图中的【发髻高度、饰品方向和服装】保持严格一致。

**图内排版指令**（图鉴风关键技巧，可选）：

> 左上角加入中文标题"【名称】"，下方关键词"【词1／词2／词3／词4】"，文字浅银灰棕，清晰准确，排版简约。

**背面信息量**：必写一句「背面重点展示【高髻中心与左右羽状发束/三枚连珠发髻与编发连接】的结构」，否则背视图容易糊弄。

## 版式 C：妆造设定卡（一人多 Look）

**适用**：同脸不同妆造对比、Lookbook 式定妆照。

**布局声明写法**：

> 生成一张现代女性角色妆造设定卡，竖版3:4比例，超写实照片级质感，专业时尚画册风格，电影级柔光，浅米白色纯净摄影棚背景。整张图片分为上下两个独立造型区域，每个区域展示同一名年轻亚洲女性的不同妆造。每个区域的排版结构：左侧为人物上半身正面肖像特写，重点展示脸型、五官、妆容、发型、耳饰、项链和服装领口细节；中间为造型文字说明区域，包括Look编号、造型名称、发型、风格、配色、单品；右侧并列展示人物全身正面、90度侧面、背面三视图，人物从头到脚完整入镜，三视图保持相同脸型、五官、身材比例、服装结构和发型。

**Look 文字区字段**：Look 编号 / 造型名称（如"清冷都市感"）/ 发型 / 风格 / 配色 / 单品。

**整体视觉收尾**：

> 米白、奶油色、低饱和莫兰迪配色，柔和自然光，干净留白，细腻皮肤纹理，服装面料真实，时尚品牌Lookbook，高级人物设定档案，版式整齐，字体放大，信息层级清晰。

## 版式 D：3D 建模图纸风三/四视图（建模参考向）

**适用**：漫剧建模参考、需要工整对称的技术向设定图。四视图 = 正面/侧面/背面/半侧（3/4 视角比三视图更利于建模对照），或"四视角四分格定妆照"（正面近景特写+正面全身+侧面+背面）。

**布局声明写法**：

> 【风格】3D 建模角色，工业技术图纸标准排版。左侧放正面看镜头大头部细节展示，右侧放人物三视图（正面／正侧面／背面），人物比例统一、身形细节完全对称一致。

**画面规格收尾**：

> 纯白极简无杂质背景，8K 超写实 3D 仿真，真人质感十足，精准还原【材质1肌理、材质2光泽、发丝层次】，全局柔和自然光影，轮廓结构线条工整规范，建模级标准三视图构图，无多余元素、无畸变崩坏。

## 版式 E：四视角定妆照 · 四宫格拼接（写实定妆向，男主常用）

**适用**：超写实定妆照、影视定妆/建模/场景拍摄参考；四个维度信息量最大。

**布局声明写法**：

> 生成一张【风格主题】的【男性/女性】角色四视角定妆照，通过正面近景、正面全身、侧面、背面四个维度，完整展示一套【造型描述】。构图：四宫格拼接构图，分别展示正面近景、正面全身、侧面、背面，全方位呈现角色完整造型，角色居中，画面饱满。

**分视角侧重点标注**（关键技法——给每个视角指定展示重点，背/侧视图不再糊弄）：

> 四宫格拼接构图，分别展示正面近景（侧重神态与精致五官）、正面全身（侧重穿搭版型）、侧面（侧重流畅骨相轮廓）、背面（侧重剪裁与暗纹细节），全方位呈现角色造型。

**布光收尾**：

> 专业影棚柔光拍摄，纯净浅白色极简背景，采用全局漫反射柔光+侧方弱光影，极致柔化肌肤瑕疵，保留面部骨相层次；光线柔和勾勒【面料纹理、金属配饰微光、真皮哑光质感】，凸显【气质词】的高级氛围感。

## 超写实一致性锁定前缀（即梦实测，写实数字人专用）

放在提示词最开头，用"参数化锁定"强制一致性与去 AI 感，做**系列图/多视角**时尤其有效：

> 非真人拍摄，纯AI生成虚拟数字人，无真人素材，无真人换脸，超写实虚拟人模型，统一【暖金青灰】调色板（【米白40%+浅棕30%+淡金20%+青灰10%】），对比度固定30%，饱和度固定25%，统一柔和顶光+侧补光，无夸张打光，无逆光黑脸，皮肤细腻通透带自然肌理（非毛孔），有轻微皮肤光泽和血色感，无硅胶脸，无塑料感，无AI失真，五官精致立体，面部线条柔和，头发有自然碎发和发丝层次感，衣服有真实面料褶皱和垂坠感，人物比例标准（头身比1:7.5），表情自然不夸张，动作幅度适中，全程人物五官/发型/服装/色调/光影100%固定不变，禁止AI自行调整任何风格参数。

要点：
- **调色板写百分比**（主色40%+辅色30%+点缀20%+10%），比"低饱和莫兰迪"更可控
- **对比度/饱和度写固定数值**
- "100%固定不变 + 禁止AI自行调整任何风格参数"是最强一致性声明，适合即梦/可灵
- "非真人拍摄，纯AI生成虚拟数字人，无真人素材，无真人换脸"同时是合规声明，写实向建议保留
- 去 AI 感三连：无硅胶脸、无塑料感、无AI失真；配"自然肌理（非毛孔）+ 血色感"

## 一致性话术全集（按需组合，至少用三条）

| 话术 | 作用 |
|------|------|
| 同一人物／同一位……的三种视图 | 声明同一角色 |
| 人物、发型、服装纹样、饰品和比例完全统一 | 锁细节 |
| 全视角人物完全统一、细节复刻无偏差 | 锁细节（变体） |
| 三个视图中的【发髻高度、饰品方向、服装】保持严格一致 | 点名易崩项 |
| 人物比例统一、身形细节完全对称一致 | 锁身形 |
| 完整全身构图，从头顶到鞋履全部展示，无裁切 | 防半身/缺脚/裁裙摆 |
| 脚部完整可见 | 防裁脚 |
| 背面重点展示【……】结构 | 强制背视图信息量 |
| 三视图自然直立，手臂稍离身体，正侧背结构完整明确 | 标准站姿 |

## 背景与灯光标准配置

- 背景：纯白无缝影棚 / 淡青灰摄影棚 / 浅米白纯净摄影棚 / 纯净象牙白——设定图一律纯色棚拍背景，禁止复杂场景
- 灯光：柔和冷白色漫射棚拍光，正面柔光，轻微轮廓光和发丝光，低对比度，柔和阴影
- 特写光变体：柔和晨光从侧面照亮面部和【玉石/金属饰品】，肤色明亮，黑发轮廓清楚
