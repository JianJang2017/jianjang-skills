# 服装库：公式 + 古风/现代词库

## 服装提示词公式

**结构 + 颜色（主色 2-3 个）+ 材质 + 纹样**，四要素缺一不可。

- 古风写内外层结构：「整体主色为浅青色、月白色和淡竹绿色。内层长裙为月白色，外层轻纱罩衫呈淡青至浅绿的柔和渐变。衣襟、袖口、腰封和裙摆边缘带有浅银色草药纹、兰草纹和云纹刺绣」——比"穿着漂亮青色汉服"稳定得多
- 现代写上装/内搭/下装/鞋/配饰逐件：「身穿白色短款机能风外套，配有浅银色细反光条，内搭淡蓝色高领修身打底衫，下配浅灰色高腰直筒长裤，脚踩白色厚底短靴，耳畔戴一条水滴形银色耳坠」
- 材质逐件给质感（3D 向配 PBR）：「机能外套硬挺带细微光泽，反光条细闪，打底衫柔软贴合，发丝柔亮通透」
- **识别点收敛**：三视图中纹样越复杂越容易崩，挑 2-3 个识别点（如斜襟+玉扣+兰花刺绣）写足细节，其余装饰简化
