## 定妆容方法论

同脸不同妆即可做出完全不同的人设——前提是**脸型、五官比例、肤色、瞳孔颜色和基础发色始终保持不变**，变化的只是眉形、眼影、眼线、腮红、唇色、发型和服装。

妆容按 9 部位拆解描述，每项一个 6-10 字短语，按人物性格调整颜色/浓淡/线条：

| 部位 | 写法示例 |
|------|----------|
| 底妆 | 轻薄透亮底妆 / 奶油柔雾底妆 / 清透半哑光底妆 / 通透水光底妆 |
| 眼影 | 浅米杏色 / 蜜桃色 / 灰棕色 / 烟玫瑰色（低饱和为主） |
| 眼线 | 内眼线自然填补 / 上扬猫系眼线 / 细长冷调内眼线 |
| 睫毛 | 根根分明纤长 / 浓密卷翘 / 清透纤长 |
| 眉形 | 柔和自然眉 / 平直利落眉 / 自然野生眉 / 浓密自然眉 |
| 腮红 | 浅粉色 / 暖粉横扫眼下 / 灰粉色低饱和 / 豆沙棕 |
| 修容 | 面部轮廓立体 /（清淡妆可省略） |
| 高光 | 细腻自然高光 / 提亮T区颧骨鼻梁 |
| 唇色 | 水润裸粉 / 蜜桃粉唇釉 / 酒红丝绒 / 冷调豆沙 |

收尾加 2 个气质词：如"干净柔和，日常自然感""明艳自信，港风复古高级感"。

## 妆容设定卡版式（单独出妆容定妆图时用）

信息架构（配合 layout-templates.md 版式 C）：

- **基础信息**：年龄 / 风格 / 妆容关键词 / 肤质 / 气质
- **角度展示**：正面、45°侧颜、侧颜、背面（妆容卡也用多视图锁一致性）
- **面部细节特写**：眼妆 / 睫毛 / 唇妆 / 肌肤细节
- **妆容拆解九宫格**：底妆、眼影、眼线、睫毛、眉毛、腮红、修容、高光、唇妆，每项 8 字左右短语（如"蜜桃色腮红 横向晕染""提亮T区 颧骨/鼻梁"）
- **色板参考**：具名色卡（奶油白/浅米色/蜜桃杏/奶茶棕/淡粉色/裸粉色）
- **身体与材质**：颈部/手部/裙摆/鞋子 + 面料（雪纺/蕾丝/棉麻/针织）

## 防"网红脸"话术

人物设定末尾加：**"不是网红脸，真实生活感，高辨识度"**；写实向再加"清透伪素颜"、"保留自然皮肤纹理"。神态描述比五官罗列更防流水线脸——写眼神与微表情（"眼神软糯清澈""眼神清冷又软""眼神平静专注"）。
