# 发型库：公式 + 古风/现代词库

## 发型提示词公式

**发型结构 + 刘海/碎发 + 发饰（材质+造型）+ 身份气质（+ 服饰风格收尾）**

示例：高盘发 + 颊侧碎发 + 金色步摇 + 贵气公主 + 华丽宫廷汉服

发饰不要只写"精美发饰"，要写材质和造型：银白羽毛造型发簪、雪花形白玉、透明水晶与细银链。

发型与身份匹配速查：女将军=高马尾+发冠+黑玉发簪；医女=低发髻+青玉发簪+浅色丝绦；舞姬=半盘半披+金色流苏+玛瑙珠链；女先生=低盘发+白玉发簪+素银发扣；女术士=星月发簪+紫水晶+流苏步摇。

发型三视图专用：结构逐层描述（主髻位置/层次/额前碎发/后脑处理），并写明「背面重点展示【发髻中心/编发连接/垂发】结构」。
