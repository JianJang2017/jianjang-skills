# Character Turnaround Skill（角色三视图工厂）

为 AIGC 流程生成**角色三视图设定图提示词**，核心目标是「定角色、定妆容」：
一次把角色的脸、妆、发、衣锁定下来，落盘成角色档案，后续所有分镜、立绘、动作图都引用同一档案，保证角色不跑偏。

## 核心理念

一张好看的立绘只说明"第一眼长什么样"，不代表能稳定复用。换镜头后常见问题：腰饰消失、袖口衣领变样式、气质跑偏。解法是**把固定元素提前拆开写清楚**——脸型、五官、肤色、瞳色、发色锁死为"不变项"，服装、配色、材质、配饰逐项固定，妆容按部位拆解。角色档案就是这份"合同"。

三条经验法则（来自大量实测文章）：

1. **不变项锁定**：脸型、五官比例、肤色、瞳孔颜色、基础发色始终保持不变；变化的只是眉形、眼影、眼线、腮红、唇色、发型和服装。
2. **识别点收敛**：纹样越复杂，三视图越容易出现差异。优先保留 2-3 个视觉识别点（如：斜襟 + 玉扣 + 兰花刺绣），其余装饰适当简化。
3. **一致性要显式声明**：不要依赖模型自觉，提示词里必须写"同一人物""人物、发型、服装纹样、饰品和比例完全统一""从头顶到鞋履全部展示，无裁切"。

## 工作流

### 第一步：理解需求，确定风格与用途

从用户描述中确定：

- **风格域**：古风/仙侠、新中式、现代都市、3D 建模风、韩系、Y2K、职场、礼服等
- **用途**：短剧/漫剧人设、建模参考、定妆照、系列角色
- **画风**：半写实 3D 国漫 / 超写实真人 / 3D 建模图纸风 / 国风插画
- **数量**：单个角色，还是同脸多妆容（一人多 Look），还是系列角色

需求开放时（如"帮我设计一个古风女主"），给出 2 个方向概念（身份 + 气质 + 配色一句话）让用户选，不要直接生成大段提示词。需求明确时直接进入第二步。

### 第二步：定角色（锁定不变项）

按以下清单确定角色核心设定。用词要具体，服务于角色身份——女将军眉眼锐利、下颌线干净；医女面部线条柔和、眼神温润。忌所有角色同一张"精致鹅蛋脸"。

| 维度 | 要求 |
|------|------|
| 人设定位 | 年龄（明确成年，如 24 岁）+ 身份 + 一句话故事感 |
| 气质 | 组合出层次，不写单词。如"温婉安静、清雅亲和，带有医者的从容与淡淡书卷气" |
| 脸型骨相 | 鹅蛋/瓜子/圆润/偏窄，额头、下颌线 |
| 五官 | 眉形、眼型眼色、眼神、鼻、唇色，各自具体 |
| 肤色 | 冷白/暖白/白皙偏暖 + 通透度 |
| 身形 | 高挑/纤细/柔韧 + 肩背腰肢 |
| 识别点 | 挑 2-3 个最有辨识度的视觉锚点，写进档案 |

### 第三步：定妆容

读取 `references/makeup-library.md`。妆容按 9 部位拆解描述：**底妆、眼影、眼线、睫毛、眉形、腮红、修容、高光、唇色**，按人物性格调整颜色/浓淡/线条。

- 用户没有明确妆容偏好时，从 8 套预设方案中按人设气质推荐 1-2 套（清透裸感/元气蜜桃/韩系初恋/温柔奶杏/复古港风/冷感高级/甜酷猫系/微醺玫瑰）
- 做"一人多 Look"时，只换妆容发型服装，脸部不变项原样复制

### 第四步：定发型与服装

- 发型：读取 `references/hairstyle-library.md`，按公式「发型结构 + 刘海/碎发 + 发饰（写明材质和造型）+ 身份气质」。发饰不要只写"精美发饰"，要写"青玉发簪、浅绿色丝绦、白色小花发饰"这种材质+造型。
- 服装：读取 `references/costume-library.md`，按公式「结构 + 颜色（主色 2-3 个）+ 材质 + 纹样」，古风写内外层结构，现代写上装/下装/鞋/配饰。

### 第五步：组装三视图提示词

读取 `references/layout-templates.md` 选版式，读取 `references/prompt-framework.md` 套八段式框架。

**版式选择**：
- 默认：**横版 16:9「左 40% 头肩特写 + 右 60% 正/侧/背三全身」**——最通用，适合角色设定图
- 发型/妆容特写为主 → 竖版 3:4 三视图图鉴（左下最大正面、右上侧面、右下背面）
- 一人多 Look → 妆造设定卡（肖像特写 + 文字说明区 + 三视图，一图双 Look）
- 建模参考 → 四视图（正/侧/背/半侧）+ "建模级标准三视图构图，工业技术图纸标准排版"

**提示词组装顺序（八段式）**：
版式与布局声明 → 人物基础设定 → 五官与神情 → 发型发饰 → 妆容 → 服装与材质 → 姿态构图（含一致性话术）→ 背景灯光 + 画质尾缀 + 负面提示词

**一致性话术必须包含**（不可省略）：
- "同一人物/同一位……的三种视图"
- "人物、发型、服装纹样、饰品和比例完全统一"（或"全视角人物完全统一、细节复刻无偏差"）
- "完整全身构图，从头顶到鞋履全部展示，无裁切，脚部完整可见"
- 背面视图信息量：加一句"背面重点展示……结构"（如发髻结构、背部盘扣）

### 第六步：落盘角色档案（必做）

将角色档案保存到 `characters/<角色名>.md`（相对当前工作目录；用户指定了目录则用用户的）。档案结构固定如下：

```markdown
# 角色档案：<角色名>

## 基本信息
- 人设定位 / 年龄 / 身份 / 气质 / 用途

## 定角色 · 不变项（任何场景不得改动）
- 脸型骨相 / 五官 / 肤色 / 瞳色 / 基础发色 / 身形
- 识别点：<2-3 个视觉锚点>

## 定妆容（当前 Look）
- 底妆 / 眼影 / 眼线 / 睫毛 / 眉形 / 腮红 / 修容 / 高光 / 唇色

## 发型发饰

## 服装造型
- 主色 / 结构 / 材质 / 纹样 / 鞋 / 配饰

## 三视图提示词（完整可复制）
<完整提示词全文>

## 负面提示词
<负面词全文>

## 复用指引
后续生成该角色的分镜/动作/场景图时：原样复制「不变项」+「当前 Look 妆容」段落，
只替换姿态、场景、构图部分。

## Look 变体记录
（新增妆造时追加 Look 2 / Look 3……每个含妆容+发型+服装+对应提示词）
```

### 第七步（可选）：直接生成三视图图片

用户要求出图时，调用 image-factory-skill 的生图脚本（codex/agy 后端）：

```bash
node <path-to>/image-factory-skill/scripts/generate-image.js \
  --prompt-file /tmp/turnaround-prompt.md \
  --output characters/images/<角色名>-turnaround.png \
  --aspect-ratio 16:9
```

- 版式是横版 16:9 就传 `16:9`，竖版图鉴传 `3:4`
- 提示词先写入临时文件再用 `--prompt-file`，避免 shell 转义问题
- 并发批量生成多个角色时，每次调用使用独立临时 `CODEX_HOME`，避免图片串档
- 生成后把图片路径回填到角色档案的「三视图提示词」段落下方

## 输出格式（对话中）

```
【角色】<角色名> · <人设定位>
【版式】<横版16:9三视图 / 竖版3:4图鉴 / 妆造设定卡 / 四视图>
【识别点】<锚点1 / 锚点2 / 锚点3>

【三视图提示词】
<完整提示词，可直接复制到即梦/可灵/Nano Banana/GPT-image>

【负面提示词】
<负面词>（注：GPT-image/Nano Banana 不支持独立负面词栏时，已将关键约束以"无XX"形式并入正文）

【已保存】characters/<角色名>.md
```

## 平台适配说明

输出的是通用中文自然语言长提示词，各平台使用差异：

- **即梦 / 可灵**：正文 + 负面提示词分栏填入，原样可用
- **Nano Banana / GPT-image / gpt-image-2**：不支持独立负面词，把关键负面约束写成正文末尾的"无文字，无水印，无畸变崩坏"式短语（模板已包含）；16:9 选横版分辨率
- **Midjourney / SD**：本技能默认不输出 tag 串/参数后缀；用户明确要求时，将段落压缩为短语串并附 `--ar` 参数

## 安全与质量红线

- 年龄明确标注为成年（22-28 岁等具体数字）；避免任何未成年化描述（"幼态化"必须进负面词）
- 不冒用真人姓名/明星脸；不使用侵权 IP 角色名，用"原创"或"XX 风格"
- 避免过度性感化、暴露描述（进负面词）
- 人体比例、手部解剖约束进负面词（多余手指、肢体扭曲等）
