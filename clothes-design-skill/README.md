# Clothes Design Skill（服装设计工厂）

从设计需求到生产规格书的一站式输出：

- **样衣效果图**：成衣平铺展示，可选手绘/水彩/3D/摄影风格
- **裁片分解图**：SVG 矢量技术图纸，尺寸由尺码表计算得出（非 AI 生成），含净样/毛样/对折线/布纹方向/逐处标注
- **国际尺码表**：XS-XXXL 全档（可按需指定子集），每码的胸围/腰围/臀围/肩宽/袖长/衣长
- **面料用量核算**：按参考尺码计算总米数、幅宽、裁片数、排料效率
- **成本明细**：面料成本（含单价依据）、辅料成本、人工成本（含工时）、管理费用，附估算假设说明

## 两种工作模式

### 模式 A：正向设计（从需求到规格）

输入：款式类型 + 风格 + 面料 + 尺码  
输出：效果图 + 裁片图 + 规格书

示例：
- "设计一件古风交领上衣，白底蓝色刺绣，棉麻面料，M码"
- "做一条黑色高腰阔腿裤，全尺码"

### 模式 B：逆向克隆（从图片到规格）

输入：衣服图片 + 用户确认的面料/尺码  
输出：克隆版效果图 + 裁片图 + 规格书

流程：反推图片设计要素（`reverse-prompt.js`）→ 用户确认细节 → 生成规格

## 款式覆盖

- **上衣**：T恤、衬衫、女式上衣/罩衫、夹克、大衣
- **下装**：裤子（含牛仔裤）、半身裙
- **连衣裙**：短裙/长裙、分割式/直身式
- **特殊**：古风交领/对襟上衣、运动服

## 面料库

内置 8 种常见面料的价格与特性（棉、麻、丝、毛、涤纶、混纺、针织、牛仔）；未收录的面料按中档 ¥30/米 估算并标注为假设。

## 尺码标准

国际通用递增规律：
- 上衣：胸围 +4cm/档，肩宽 +1cm/档，衣长 +2cm/档
- 下装：腰围 +4cm/档，裤长 +2cm/档，大腿围 +2cm/档
- 连衣裙：综合上下装测量点

用量与成本按「参考尺码」计算（包含 M 时用 M，否则取请求范围中间码），避免用 M 的数字充当 XXXL 的用量。

## 工具依赖

- **Python 3** >=3.6 — 裁片图 + 规格书（**纯标准库，零外部依赖**）
- **Node.js** >=18 — 仅效果图需要
- **至少一个图片生成后端** — 仅效果图需要：bl（百炼，免费）/ codex-cli / agy / qwen

> 没装 Node 或生图后端也能出裁片图和规格书，只是出不了效果图。

## 快速开始

生成一件 T恤的完整规格书：

```bash
# 1. 生成效果图
cat > /tmp/t-shirt-prompt.md << 'EOF'
---
aspect_ratio: "3:4"
---

PROMPT:
[Style: 手绘风格，温暖米白背景，黑色墨线，彩色色块填充]
[Type: 服装设计效果图]
一件纯白色圆领 T恤，纯棉质感，短袖，直摆，正面平铺展示，白色背景。

[Key elements]
- 款式：基础圆领 T恤
- 颜色：纯白
- 面料：纯棉，柔软质感
- 细节：圆领、短袖、下摆直线
EOF

node scripts/generate-image.js \
  --prompt-file /tmp/t-shirt-prompt.md \
  --output /tmp/t-shirt-sample.png \
  --aspect-ratio 3:4

# 2. 生成裁片图（计算生成，不用 AI 生图；尺寸自动从尺码表推导）
python3 scripts/draw_pattern.py \
  --type t-shirt \
  --size M \
  --fit regular \
  --fabric-width 140 \
  --title "基础圆领T恤" \
  --output /tmp/t-shirt-pattern.svg

# SVG 转 PNG（保持比例；交付仍用 .svg）
bash scripts/svg2png.sh /tmp/t-shirt-pattern.svg

# 3. 计算尺码表、用量、成本
python3 scripts/calculate_garment.py \
  --type t-shirt \
  --category tops \
  --fabric cotton \
  --output /tmp/t-shirt-spec.md

# 查看规格书
cat /tmp/t-shirt-spec.md
```

## 局限性

1. **面料用量是估算值**：基于矩形外接框和标准排料效率，实际因花型对位、斜裁可有 ±10% 浮动
2. **成本仅供参考**：面料价格按市场均价，实际受批量、地域、品牌影响
3. **不涵盖复杂工艺**：手工刺绣、钉珠、特殊染整等高定工艺未计入成本
4. **图片反推准确度有限**：依赖 AI 视觉识别，复杂款式可能识别不准

裁片图的尺寸数字是准确的（从尺码表推导 + 出图前自动校验标注与几何一致），但：

5. **是 1:N 示意图，不是可裁剪纸样**：不导出 DXF/PLT，落地需打版师出 1:1 实样
6. **曲线为贝塞尔近似**：袖窿、裆弧形状对但不够顺，影响合体度不影响尺寸核对
7. **省道未展开**：只给收量数值，未画省道形状；不支持胸省转移、公主线分割
8. **袖山/袖窿只做比例匹配**：未实测弧长，装袖前需打版师核对吃势
9. **不含工艺细节**：扣位、袋位、明线、粘衬范围均未标注

完整说明见 `references/pattern-engineering.md`。
