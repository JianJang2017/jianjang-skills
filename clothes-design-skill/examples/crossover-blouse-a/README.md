## 校验摘要

- `test_pattern_geometry.py`：17 项测试全部通过，涵盖前片差异、真实毛样偏移、轮廓拓扑、缝合边长度、领条长度、刀口落点、拼装图同源性、独立标签卡片、防重叠和双语标题。
- 裁片输出：6 种、共 7 片；SVG 文件有效并含全部裁片名称。
- 规格 smoke checks：尺码单调性、不同幅宽用量关系和基础成本模型通过；该测试文件是脚本式检查，`unittest` 计数显示 0，不虚报为单元测试数量。
- 样衣图人工检查：交领、右衽视觉关系、长袖、腰带和亚麻质感清楚；无文字、无品牌、无水印。

## 假设、风险与待确认项

- M 码使用技能内置标准尺码：胸围 88、腰围 70、臀围 94、肩宽 38、袖长 60、衣长 64cm；不是品牌专属号型。
- 3.69m 用量基于 110cm 幅宽和 66% 估算排料效率，不可直接形成采购单。
- ¥343.39 为市场均价模型，不可直接签订报价合同。
- 样衣图中的穿着褶皱和色彩仅是视觉提案，不能证明内部工艺。
- 亚麻缩水、克重、纬斜、粘衬、针距、线迹、整烫和公差均须实料确认。
