# Prompt Framework（服装设计图提示词框架）

> 本文后半部分保留的裁片图段落属于历史概念图提示词，仅供理解视觉构图，**不得用于生成技术裁片**。带尺寸的交付图必须由 `draw_pattern.py` 确定性生成；具体 1:5、1:10 等字样不代表可量取或可裁剪比例。

服装设计图分为两类：**样衣效果图**（展示成衣效果）和**裁片分解图**（技术打版图纸）。两者的提示词结构不同。

## 样衣效果图 Prompt 结构

### 基本模板

```
[Style: 视觉风格]
[Type: 服装设计效果图]
[Content: 款式描述]
一件/条[款式类型]，[风格特征]，[面料质感]，[颜色]，[关键细节]。
[展示方式]，[背景]。

[Key elements]
- 款式：[具体款式名称]
- 颜色：[主色调 + 配色]
- 面料：[面料类型及质感描述]
- 细节：[领型、袖型、扣子、装饰等]
```

### 视觉风格选项

#### 1. 手绘风格（Hand-drawn Style）

**关键词：**
- 温暖米白背景（warm cream background）
- 黑色墨线（black ink lines）
- 彩色色块（pastel color blocks）
- 手绘质感（hand-drawn texture）

**适用场景：**
- 概念设计阶段
- 客户提案展示
- 设计师草图风格

**示例：**
```
[Style: 手绘风格，温暖米白背景，黑色墨线勾勒轮廓，彩色色块填充，手绘质感]
[Type: 服装设计效果图]
一件古风交领上衣，白色底色，浅蓝色兰花刺绣点缀领口和袖口，
棉麻质感，交领设计，宽袖，腰部系带，下摆微微开叉。
正面平铺展示，完整呈现衣身、袖子、领口、下摆，无模特穿着，简洁背景。

[Key elements]
- 款式：古风交领上衣
- 颜色：白色+浅蓝色刺绣
- 面料：棉麻，自然褶皱质感
- 细节：交领、盘扣、宽袖口、腰带、兰花刺绣
```

#### 2. 水彩风格（Watercolor Style）

**关键词：**
- 柔光（soft light）
- 纸张质感（paper texture）
- 水墨晕染（ink bleed）
- 水彩笔触（watercolor brushstrokes）

**适用场景：**
- 女装、童装
- 家居服、睡衣
- 柔和、温馨的款式

**示例：**
```
[Style: 水彩风格，柔光，纸张质感，水墨晕染边缘]
[Type: 服装设计效果图]

裙摆自然垂坠，侧边隐形拉链。
正面平铺展示，白色背景。

[Key elements]
- 款式：A字半身裙
- 颜色：粉色碎花
- 面料：纯棉，轻薄柔软
- 细节：高腰线、侧拉链、裙摆自然垂坠
```

#### 3. 3D 渲染风格（3D Rendering Style）

**关键词：**
- 柔光照明（soft lighting）
- 景深效果（depth of field）
- 真实材质（realistic materials）
- 高清渲染（high-resolution rendering）

**适用场景：**
- 电商产品图
- 样品确认
- 最接近实物的展示

**示例：**
```
[Style: 3D 渲染风格，柔光照明，景深效果，真实材质，高清渲染]

长袖，内衬灰色里布，胸前口袋装饰方巾。

[Key elements]
- 款式：西装外套
- 颜色：黑色外层+灰色里布
- 面料：羊毛，挺括质感
- 细节：翻领、双扣、胸袋、袖扣
```

**关键词：**

- 产品摄影（product photography）

**适用场景：**

- 库存展示
- 真实拍摄效果

## 裁片分解图 Prompt 结构

### 固定风格：科技蓝图

裁片图统一使用**科技蓝图风格**，这是行业标准的技术图纸样式。

### 基本模板

```
[Style: 科技蓝图风格]
[Type: 服装裁片分解图]
[Content: 打版技术图]
[款式名称]的裁片分解图，1:10 比例示意图。

包含以下裁片，每片独立展示，标注尺寸：
- [裁片1名称]：[形状描述] + 关键尺寸标注（长×宽）
- [裁片2名称]：[形状描述] + 关键尺寸标注
- [裁片3名称]：...

蓝图网格背景，白色线框，青色调，专业打版制图风格。
每个裁片旁边标注：[裁片名称][数量][主要尺寸]。
```

### 关键词固定组合

- **蓝图网格背景**（blueprint grid background）
- **白色线框**（white wireframe lines）
- **青色调**（cyan tone）
- **尺寸标注**（dimension annotations）
- **专业打版制图风格**（professional pattern-making diagram style）

### 裁片描述规范

每个裁片需要包含：
1. **名称**：前片、后片、袖子、领子等
2. **数量**：× 1 / × 2（对称裁片）
3. **形状描述**：矩形、梯形、弧形等
4. **尺寸标注**：长度 × 宽度，单位 cm

## 提示词写作要点

### 样衣效果图

1. **展示方式统一**：
   - ✅ "正面平铺展示，完整呈现衣身、袖子、领口、下摆，无模特穿着"
   - ❌ 避免"模特穿着"（会生成人物，偏离服装设计图焦点）
   - ❌ 避免"侧面"、"背面"（初稿只需正面）

2. **背景简洁**：
   - ✅ "白色背景" / "简洁背景"
   - ❌ 避免复杂场景（"在咖啡厅"、"街头"等会分散注意力）

3. **面料质感要具体**：
   - ✅ "棉麻质感，自然褶皱"
   - ✅ "真丝光泽，柔软垂坠"
   - ✅ "牛仔布，厚实挺括"
   - ❌ 避免笼统的"高级质感"

4. **细节要拆解**：
   - ✅ "交领设计，盘扣，宽袖口，腰带"（逐项列举）
   - ❌ "古风元素"（太笼统）

### 裁片分解图

1. **风格不要变**：
   - 所有裁片图统一使用科技蓝图风格
   - 不要用手绘、水彩、摄影等其他风格

2. **比例要标注**：
   - 必须写明"1:10 比例示意图"或"1:5 比例"
   - 这不是可打印的 1:1 纸样，只是示意

3. **裁片排列要说明**：
   - "横向排列：前片-后片-袖子"
   - "纵向排列：主体部件在上，小部件在下"
   - 帮助模型组织布局

4. **尺寸标注要明确**：
   - 每个裁片必须有"长 × 宽"或关键尺寸
   - 即使是 AI 生成的图，标注也能提示模型画出刻度感

## 颜色描述规范

- **单色**："纯白色"、"深蓝色"、"黑色"
- **双色**："白色底+浅蓝色刺绣"、"黑色外层+灰色里布"
- **图案**："粉色碎花图案"、"条纹（蓝白相间）"、"格纹（黑白格）"
- **渐变/特殊**："扎染效果"、"磨白处理"、"褪色牛仔蓝"

---

## Aspect Ratio 选择

| 图片类型 | 推荐比例 | 理由 |
|---------|---------|-----|
| 样衣效果图 | 3:4（竖版） | 服装通常是竖长形，竖版能完整展示 |
| 样衣效果图（外套） | 2:3 或 3:4 | 外套较长，竖版更合适 |
| 裁片分解图 | 16:9（横版） | 多个裁片横向排列，横版空间利用率高 |
| 裁片分解图（复杂款） | 4:3 或 1:1 | 如果裁片很多，可用接近方形的比例 |

**使用说明：**

生成样衣效果图时，根据用户的款式和风格需求，从四种视觉风格（手绘/水彩/3D/摄影）中选择最合适的一种。生成裁片图时，统一使用科技蓝图风格，从 `references/garment-library.md` 中查找对应款式的裁片构成，填入 prompt。
