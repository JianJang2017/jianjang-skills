# 成本核算模型

本文档说明 `scripts/calculate_garment.py` 的成本计算逻辑，以及在什么情况下应该覆盖默认值。

读这份文档的时机：用户质疑成本数字、要求调整费率、或者需要向工厂/客户解释报价构成。日常生成规格书直接跑脚本即可，不必展开这里的细节。

## 总成本公式

```
直接成本 = 面料成本 + 辅料成本 + 人工成本
总成本   = 直接成本 × (1 + 管理费率)
```

默认管理费率 15%。这是单件出厂成本，不含利润、不含物流、不含税。

四项的典型占比（以棉质衬衫为例）：

| 项目 | 金额 | 占比 |
|------|------|------|
| 面料 | ¥78 | 37% |
| 辅料 | ¥12 | 6% |
| 人工 | ¥120 | 57% |
| 小计 | ¥210 | — |
| 管理费 15% | ¥31.5 | — |
| **总计** | **¥241.5** | |

**人工通常是最大头**，这一点常被低估。设计师容易盯着面料价格砍成本，但一件工序复杂的衣服，省下的面料钱远抵不上多出来的工时。想降本，先简化工艺（少一道拼接、少一排扣眼），比换便宜面料有效得多。

## 面料成本

```
面料成本 = 面料单价(元/米) × 用量(米)
```

单价来自 `references/fabric-database.md`。用量由脚本按裁片面积和幅宽推算，见下文。

**影响实际采购价的因素**（脚本无法预知，需人工判断）：

- **起订量**：小批量（<100米）通常比数据库价格高 20-40%；大批量（>1000米）可低 10-20%
- **色号**：常规色按标准价，特殊色/小众色需要单独染缸，加价明显
- **进口 vs 国产**：同类面料进口价可达国产 2-3 倍
- **季节**：旺季（春夏装备货期）面料涨价

数据库里的价格是**中等批量、常规色、国产**的市场均价，适合做初期估算和方案对比，不适合直接拿去签采购合同。

## 辅料成本

辅料按款式给固定估值，因为它是一堆小件的总和，逐项列出反而不好用：

| 款式 | 辅料成本 | 主要构成 |
|------|---------|---------|
| T恤 | ¥5 | 织唛、洗水标、吊牌、缝线 |
| 衬衫 | ¥12 | 纽扣×10、领撑、织唛、洗水标、吊牌 |
| 上衣/衬衣 | ¥10 | 纽扣或拉链、织唛、标签 |
| 连衣裙 | ¥18 | 隐形拉链、里布、挂钩、织唛、标签 |
| 半身裙 | ¥12 | 拉链、腰衬、挂钩、标签 |
| 裤子 | ¥15 | 拉链、纽扣、腰衬、口袋布、标签 |
| 夹克 | ¥35 | 金属拉链、里布、罗纹、纽扣、标签 |
| 大衣 | ¥50 | 大纽扣、全里布、垫肩、挂面、标签 |

**什么会让辅料成本跳升：**

- 金属五金（真铜扣、YKK 金属拉链）比塑料件贵 3-5 倍
- 全里布的连衣裙/外套，里布本身要按面料算，不在这个固定值里
- 品牌定制织唛、烫金吊牌，小批量摊销后单件成本很高

如果款式用了明显高于常规的辅料，直接告诉用户「辅料按标准估值 ¥X，你这个款用了金属五金，实际会高出 ¥Y 左右」，比默默用默认值更有价值。

## 人工成本

```
人工成本 = 工时(小时) × 工时单价(元/小时)
```

默认工时单价 ¥30/小时。工时按款式复杂度：

| 款式 | 工时 | 说明 |
|------|------|------|
| T恤 | 2.5h | 工序最简：合肩、上袖、合侧缝、下摆 |
| 衬衫 | 4.0h | 领子、门襟、袖克夫、扣眼，工序多 |
| 上衣 | 3.5h | 视门襟和领型而定 |
| 连衣裙 | 5.0h | 上下身组合、装拉链、可能有里布 |
| 半身裙 | 3.0h | 相对简单，主要是腰头和拉链 |
| 裤子 | 4.5h | 门襟、口袋、腰头、裤脚 |
| 夹克 | 8.0h | 里布、口袋、拉链、罗纹，工序最密 |
| 大衣 | 10.0h | 全里布、挂面、垫肩、大量熨烫定型 |

**工时单价的地域差异很大**：

| 地区 | 参考单价 |
|------|---------|
| 珠三角/长三角小厂 | ¥25-35/h |
| 内陆产业带 | ¥18-25/h |
| 东南亚（越南/孟加拉） | ¥8-15/h |
| 国内高定/样衣间 | ¥60-120/h |

默认 ¥30 对应国内常规成衣厂。做出口报价或高定报价时，这个值必须换。

**工时会显著增加的工艺：**

- 手工刺绣：按图案面积计，小图案 +1-3h，大面积可 +10h 以上
- 钉珠/亮片：+2-8h
- 手工缝边/滚边：+1-2h
- 特殊拼接（多片分割）：每增加一条分割线约 +0.3h
- 水洗做旧：外发加工，按件计费而非工时

这些都不在脚本的默认工时里。遇到含这类工艺的款式，要单独提醒用户成本会明显上浮。

## 管理费用

```
管理费用 = 直接成本 × 管理费率
```

默认 15%，覆盖：

- 打版费摊销（首版 + 修版，通常 ¥300-2000/款，按订单量摊）
- 样衣制作成本
- 质检人工
- 包装材料（防尘袋、纸箱）
- 车间水电、设备折旧
- 次品损耗（通常 2-5%）

**费率该调整的情况：**

- **小批量（<50件）**：打版费摊销压力大，实际可达 25-40%
- **大批量（>5000件）**：摊销后可降至 8-12%
- **复杂款式**：改版次数多，打版成本高，往上调
- **首单新款**：还没跑顺流程，损耗率高，往上调

脚本用固定 15% 是为了让不同款式之间可比。给用户报价时，如果知道批量，应该明确说明「这个 15% 是中等批量假设，你如果只做 30 件，管理费率实际接近 30%」。

## 面料用量推算

脚本的用量算法：

```
1. 按尺码表计算各裁片的面积（矩形外接框近似）
2. 汇总总面积
3. 除以排料效率（默认 75%）得到实际需要的布面积
4. 除以幅宽得到长度（米）
5. 向上取整到 0.05 米
```

**排料效率 75% 是保守估算。** 实际值取决于：

| 情况 | 排料效率 |
|------|---------|
| 大批量、多尺码套排、无花型限制 | 82-88% |
| 常规单款单色 | 72-80% |
| 有花型对位要求（格子、条纹、大花） | 55-70% |
| 绒毛面料（必须同向排料） | 60-72% |
| 单件打版/样衣 | 50-65% |

**矩形外接框近似会高估用量**，因为裁片实际是曲线形状（袖窿、领口都是弧线），矩形框把这些弧线外的空白也算进去了。这个高估某种程度上抵消了「实际排料能套裁得更紧」的低估，两个误差方向相反，所以最终数字在常规款式上大致合理。

但对形状特别不规则的裁片（比如大 A 摆裙片、斜裁裁片），高估会更明显。斜裁（bias cut）尤其要注意：斜 45° 排料的实际用量通常比直丝排料高 30-50%，脚本完全没有考虑这一点。遇到斜裁款式必须手工上调。

**结论：把脚本给出的用量当作「下单前的估算」，正式采购前让打版师做一次实际排料。** 脚本输出的数字用来比较方案、做初步报价、判断可行性，够用了。

## 报价与定价

成本 ≠ 报价。常见的定价倍率：

| 渠道 | 倍率（对出厂成本） |
|------|------------------|
| 批发/供货 | 1.5-2× |
| 电商自营 | 2.5-4× |
| 线下零售 | 4-6× |
| 设计师品牌 | 5-8× |
| 奢侈品 | 10-20× |

倍率里包含的不只是利润，还有仓储、物流、营销、退货损耗、渠道抽成、库存滞销风险。零售价看起来是成本的 5 倍，实际净利率往往只有 10-20%。

**用户问「这件衣服该卖多少钱」时**，给出成本 + 倍率区间 + 一句提醒：定价还要看竞品价格带和目标客群的心理价位，纯成本加成法容易定出卖不动的价。

## 什么时候该覆盖默认值

脚本的默认值适合快速估算和方案对比。以下情况必须调整，否则数字会误导用户：

| 触发条件 | 要调什么 |
|---------|---------|
| 用户说出具体产量（如「做 30 件」/「做 1 万件」） | 管理费率、面料单价 |
| 用户说出生产地（东南亚 / 高定工作室） | 工时单价 |
| 款式含手工工艺（刺绣、钉珠、手缝） | 工时 |
| 面料是格子/条纹/大花/绒毛 | 排料效率往下调 |
| 款式是斜裁 | 面料用量上调 30-50% |
| 用户提供了实际面料报价 | 面料单价 |
| 款式含全里布 | 加一份里布的面料成本 |
| 用了金属五金/定制辅料 | 辅料成本 |

调整方式：只允许覆盖商业估算（供应商单价、工时费率、管理费率或有依据的损耗率），并在规格书里明确记录原值、新值、依据与日期。不得手工修改几何、尺寸标注或任何失败校验的结果；这类问题必须修正输入或代码后重新运行。

**始终说明数字的性质。** 「面料 2.8 米、成本 ¥241」听起来像精确结论，但它是一串假设的乘积。交付时带一句「基于标准版型和 75% 排料效率估算，实际采购前建议让打版师核一次排料」，既不削弱数字的实用性，也不让用户拿着估算值去签合同。
