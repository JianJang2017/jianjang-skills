# 工业 A 级交付合同

本合同是技能的能力边界与最终交付结构的唯一权威来源。目标是生成“打版师复核包”，不是直接生产文件。

## 输入预检

建立设计简报，至少记录：

| 字段 | 处理规则 |
|---|---|
| 工作模式 | 正向设计或图片逆向分析 |
| 款式/品类 | 必须能映射到受支持类型；否则 `BLOCKED` |
| 尺码依据 | 标准尺码或人体净尺寸；缺失时不得生成确定版型 |
| 版型 | `fitted`、`regular` 或 `loose`；默认值必须披露 |
| 面料与幅宽 | 未知值可估算，但必须 `CONDITIONAL` |
| 关键结构 | 领、袖、门襟、腰头、口袋和闭合方式；关键项缺失时询问 |
| 交付范围 | 效果图、裁片示意、规格、用量、成本的实际需求 |

图片逆向分析只能把可见外观列为“观察”。面料成分、背面、内部结构、尺寸和工艺属于“推测”或“用户确认”，不得混为事实。

## 能力矩阵

| 能力 | 状态 | 边界 |
|---|---|---|
| 效果图 | 支持 | 仅用于视觉确认 |
| 1:N SVG 裁片示意 | 支持指定款式 | 不可直接裁剪 |
| 标注与几何校验 | 支持指定款式 | 只证明内置公式自洽 |
| 尺码表 | 支持 XS–XXXL | 不等于品牌专属号型 |
| 用量与成本 | 估算 | 必须披露参考尺码、幅宽、效率和价格假设 |
| 单图逆向 | 有条件支持 | 看不到或量不到的内容不能断言 |
| 1:1 纸样、DXF/PLT | 不支持 | 由专业打版师完成 |
| 工业放码、真实排料 | 不支持 | 不得模拟成已完成 |
| 工艺单、生产 BOM、公差和批量 QC | 不支持 | 属于后续工业工程阶段 |

## 交付状态

状态评价用户请求的完整目标，而不是某个局部文件。若用户要求“直接裁剪/直接投产”，完整目标超出能力，状态必须为 `BLOCKED`；可以另行提供一个 `CONDITIONAL` 的打版师复核包作为降级方案。状态按最严重问题确定：

- `PASS`：全部必交件存在；裁片和规格校验通过；所有关键输入均由用户或可核验来源确认，没有默认值、市场均价或成本回退。存在默认值或市场均价时不得标记 `PASS`。
- `CONDITIONAL`：资料可以复核，但存在已披露的默认版型、未知面料回退、价格估算、效果图失败或图片推测。
- `BLOCKED`：关键尺码/结构缺失、款式不受支持、输入无效或确定性校验失败。此状态不得声称已完成规格书。

## 打版师复核包

最终答复按此顺序输出：

1. **交付状态**：`PASS` / `CONDITIONAL` / `BLOCKED`，附一句原因。
2. **设计简报与版本**：模式、款式、尺码依据、版型、面料、幅宽和生成日期。
3. **效果图**：若存在，标注“仅用于视觉确认，不作为结构或尺寸证据”。
4. **裁片技术示意**：给出 SVG 和可选 PNG 预览，标注“1:N，不可直接裁剪”。
5. **尺寸规格**：注明人体净尺寸/成衣尺寸、单位、参考尺码和测量点。
6. **用量与成本估算**：注明幅宽、参考尺码、排料效率、价格与费率来源。
7. **校验摘要**：列出几何/标注、关键缝合关系、SVG 和输入校验结果。
8. **假设、风险与待确认项**：逐条列出脚本 `assumptions`、图片推测和默认值。
9. **打版师复核清单**：核对成衣尺寸与放松量；确认克重、弹性、缩水和幅宽；顺滑曲线并补等距缝份、刀口、省道、扣袋位、粘衬和里布；试坯修版；实际排料复核用量。
10. **下一步**：专业打版师制作、试穿并修正 1:1 工业纸样；之后才进入采购、裁剪和生产。

## 降级与失败

- 效果图失败：技术资料可继续，状态至少为 `CONDITIONAL`，说明缺失项。
- 未知面料或价格：保留脚本回退值和来源，状态为 `CONDITIONAL`；不得隐去假设。
- 图片信息不足：列出可见观察与不可确认项；关键结构不明时 `BLOCKED`。
- 单图“完全复刻”或直接生产：在运行反推或生成效果图前先判定 `BLOCKED`，避免先产出漂亮结果再弱化风险。
- 不支持的款式：可以提供概念与需打版师解决的问题，不得套用近似裁片后称已完成。
- 无效尺码或参数：停止并要求更正，不得静默跳过。
- 几何、标注或缝合关系校验失败：`BLOCKED`，不交付该裁片图。
- SVG/PNG 转换失败：优先保留通过校验的 SVG；PNG 仅为预览。

## 交付门禁

- [ ] 状态与原因位于答复开头。
- [ ] 款式在裁片引擎支持范围内，或已明确 `BLOCKED`。
- [ ] 所有关键输入有来源：用户提供、图片观察、推测或默认。
- [ ] 裁片由 `draw_pattern.py` 生成并通过内部验证。
- [ ] 规格由 `calculate_garment.py` 生成，参考尺码明确。
- [ ] 所有 `assumptions` 已进入交付物。
- [ ] 效果图与技术图用途没有混淆。
- [ ] 明确写出“1:N、不可直接裁剪”。
- [ ] 没有暗示估算值可直接用于采购签约或生产。
- [ ] 下一步明确要求打版师制作和试穿修正 1:1 工业纸样。
- [ ] 复刻第三方设计时已提醒核查商标、版权、外观设计及授权范围。

任何关键门禁失败都不能标记 `PASS`。
