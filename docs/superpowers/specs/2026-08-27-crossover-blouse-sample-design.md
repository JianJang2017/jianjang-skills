# 古风改良交领上衣验收样例设计

## 目标

生成一套供用户验证 `clothes-design-skill` 效果的完整样例。样例采用女式改良汉服交领上衣，M 码、regular 宽松度、亚麻面料、110cm 幅宽。视觉效果、裁片名称、尺寸规格和制衣顺序必须互相一致。

## 交付物

1. `01-garment-look.png`：无品牌、无文字的正面全身样衣效果图，仅用于外观确认。
2. `02-pattern-reference.svg`：由 `draw_pattern.py` 生成的完整单画布矢量裁片技术示意，可无损放大，不可直接裁剪。
3. `03-assembly-guide.svg`：由相同 `Piece.path` 生成的裁片拼装示意，不另画近似轮廓。
4. `04-making-process.md`：按裁片检查、粘衬/预处理、主体缝合、领缘、袖子、下摆、腰带、整烫和检验组织的制衣流程。
5. `05-specification.md`：M 码人体净尺寸、关键成衣尺寸、面料用量、成本估算、假设及适用边界。
6. `README.md`：样例索引、交付状态、校验摘要和打版师复核清单。

## 款式定义

- 女式改良汉服交领上衣，右衽视觉关系。
- 大襟、小襟不对称；长袖；独立领条；独立腰带。
- 亚麻自然纹理，低饱和米白与浅茶色，不使用刺绣、品牌标识或复杂装饰。
- 样衣图采用中性纯色背景、正面略带三分之二角度、全身构图，结构线清楚。

## 数据流与一致性

- `pattern_drafting.py` 是裁片几何唯一事实源。
- `draw_pattern.py` 和 `pattern_assembly.py` 从同一 M 码 draft 输出裁片与拼装图。
- `calculate_garment.py` 输出规格、用量和成本，所有默认值写入假设。
- 样衣图只表达上述款式，不作为内部结构或尺寸证据。

## 制衣流程边界

流程按常规工业样衣顺序编写，但不冒充具体工厂 SOP。针距、缝型、粘衬、缩率、整烫温度等依赖面料实测或工厂标准的数据标记为“打版师/工艺师确认”。不生成 DXF/PLT、放码、排料或批量生产文件。

## 验收

- 裁片图和拼装图均为有效 SVG，裁片数量与名称一致。
- 交领上衣几何、逐边缝份、关键缝合边及刀口测试通过。
- 规格脚本成功，输入为 tops/M/regular/linen/110cm。
- 样衣图能识别出交领、右衽、长袖和腰带，无文字、无水印、无品牌。
- README 明确区分效果图、矢量技术示意和生产纸样。
